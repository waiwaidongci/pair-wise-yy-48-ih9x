# 消防报警系统联动逻辑配置与调试审阅平台

面向消防工程师、调试人员和审阅人的联动逻辑工作台，以**调试批次（现场单号）**为单位串接设备台账、因果规则、依赖路径与验收签字。

## 技术栈

Vue 3 + Vuetify + Pinia + Vue Router + Apollo Client + GraphQL + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62048`。

```bash
npm run build   # 类型检查 + 构建
npm run verify  # 领域规则验证（合并/失效重算/签字门控/幂等恢复/迁移）
```

## 调试批次规则（核心业务）

- **设备 + 因果规则 + 依赖路径 + 验收签字接成同一批次**，全部挂在现场单号（如 `XC-2026-1004-01`）下。
- **现场 / 值班室同改同一规则：保留现场值**（现场已确认的联锁延时、优先级、互锁不被晚回记录覆盖），值班室版本进入字段级冲突队列；两端改不同字段则字段级合并。**冲突未处理不能签字**。
  - 矩阵页「模拟值班室晚回记录」可端到端演示：现场先确认 R-001/R-002/R-006，值班室晚回旧值。
- **设备分区或规则优先级、互锁、延时、启停变化后**，受影响的依赖路径自动**升版并标记失效**，挂在路径上的已通过验收结论同步作废（旧结论不再放行）；重算确认后验收项回到待测，重测通过时绑定新路径版本。
- **签字门控**：存在待处理冲突、失效路径、未通过验收、矩阵阻断错误或写入未落库，均阻断签字；锁定后配置只读，解锁修订产生新修订草稿。
- **写入失败按现场单号恢复**：失败时冻结编辑并挂起整批快照；链路恢复后用同一单号回放，服务端按「单号 + 快照摘要」幂等落库，失败/恢复审计按幂等键只记一次，不重复追加。
- **旧稿按首版迁移**：v1 本地草稿（`fire-linkage-draft-v1`）首次打开时迁移为 v2 批次，旧规则同时作为基线，路径与验收项首次建账，只产生一条迁移审计；v2 持久化在 `fire-linkage-batch-v2`。

## 页面

- 项目总览：批次门禁指标、冲突/失效路径/验收/写入状态、最近审计。
- 设备与分区：分区下拉调整即时触发路径失效重算。
- 因果矩阵：现场权威编辑、批量编辑、冲突行高亮与值班室晚回模拟。
- 依赖路径：路径版本与失效原因可视化、单条/全部重算确认。
- 冲突·验收·签字：写入故障模拟与按单号恢复、冲突处置、验收签字、矩阵校验、审计流、签字锁定。
